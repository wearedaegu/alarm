# 윈도우 알람 (windows-alarm)

여러 개의 알람을 등록하고, 정해진 시각에 소리와 팝업으로 알려주는 알람 프로그램입니다. 데스크톱(Python) 버전과 웹(브라우저) 버전 두 가지로 제공됩니다.

## 공통 기능

- 알람 여러 개 등록/삭제/켜기·끄기
- 요일 반복 설정 (선택하지 않으면 한 번만 울리고 자동으로 꺼짐)
- 알람 시각이 되면 소리 재생 + 팝업 표시, "끄기" 버튼으로 중지

## 데스크톱 버전 (Python)

- 위치: [main.py](main.py)
- 표준 라이브러리(tkinter, winsound)만 사용하므로 별도 설치 없이 실행 가능
- 실행 방법:
  ```
  python main.py
  ```
- 등록한 알람은 실행 폴더의 `alarms.json`에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 웹 버전 (브라우저)

- 위치: [web/index.html](web/index.html)
- 서버나 설치 없이 브라우저에서 파일을 직접 열면 바로 사용 가능
- 알람은 브라우저의 `localStorage`에 저장됩니다.
- **주의**: 웹 버전은 해당 탭을 열어두고 있어야 알람이 동작합니다. 데스크톱 버전과 달리 시스템 백그라운드에서 항상 동작하지는 않습니다.
